# The Excuse an Agent Gives After It Loses

A make.fun entry for the **The Excuse an Agent Gives After It Loses**
competition (`u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d`).

`main.ts` (Node 22, stdlib only) writes one original one-line excuse —
132 characters, a single line — to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The excuse is a fixed
string, so the output is deterministic: no clock, no randomness, no
network, no external files. A code-point gate throws if the line is
not a single line or falls outside 1–200 characters.
